财经媒体ESG评价体系中的"中国式现代化"话语嵌入及其对企业绿色创新的影响
——基于2025年度A+H股强制披露首年的实证研究

1.研究问题：
在中国式现代化语境下，财经媒体如何构建区别于西方ESG标准的本土化传播评价体系？该体系中"共同富裕""人与自然和谐共生"等叙事权重，是否通过信号传递机制影响企业ESG投入决策？特别是在2025年度强制披露首年，媒体对中国式现代化维度的差异化评价是否显著激励企业绿色创新？

2.研究方法：
采用内容分析法与双向固定效应模型，对2024—2026年主流财经媒体ESG报道进行编码，构建包含五个维度的"中国式现代化ESG传播评价指数"；以强制披露A+H股上市公司为样本，运用双向固定效应面板回归检验媒体评价指数对企业绿色专利产出的影响，并通过工具变量法与倾向得分匹配解决内生性问题。

3.研究价值：
突破西方ESG话语霸权，构建本土化媒体评价框架；从新闻传播学视角揭示媒体话语对企业ESG行为的"软约束"机制，为"讲好中国ESG故事"提供可量化的理论与实证支撑；同时为监管机构评估政策传播效果、企业优化ESG传播策略提供决策参考。
