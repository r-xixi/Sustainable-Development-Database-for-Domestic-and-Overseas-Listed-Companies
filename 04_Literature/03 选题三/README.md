社交媒体ESG情绪对新兴产业企业融资的影响研究

1.研究问题：
2025年度首年披露期间，雪球、东方财富等数字平台上投资者对新兴产业A+H股公司ESG报告的讨论呈现何种情感极性与认知图式？这种数字平台ESG情绪是否通过分析师预测分歧度和机构持股变动，进而缓解或加剧企业融资约束？

2.研究方法：
爬取2025年6月至2026年6月平台用户评论文本，运用BERT情感分析与LDA主题模型构建产业级ESG情绪指数，以SA指数度量融资约束，运用中介效应模型检验"数字情绪—分析师行为—融资约束"传导路径，并做十大产业异质性分析。

3.研究价值：
揭示数字平台ESG叙事对实体经济资源配置的影响路径，将计算传播学方法引入中国新兴产业投资语境。为理解新媒体环境下"媒体—市场—企业"互动关系提供实证基础，助力数字平台赋能新兴产业高质量发展的治理机制设计。
